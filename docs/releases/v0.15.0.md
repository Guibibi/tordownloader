An Unraid template and an MIT license. No changes to the app itself.

## New

- **Unraid template.** Install it on the server with:

  ```bash
  wget -O /boot/config/plugins/dockerMan/templates-user/my-tordownloader.xml \
    https://raw.githubusercontent.com/Guibibi/tordownloader/main/unraid/tordownloader.xml
  ```

  Then go to Docker → Add Container and pick **tordownloader** from the template list. It sets up
  the port, the `/downloads` and `/data` paths, your TorBox API key and the Sonarr/Radarr
  connection. A `config.yaml` in `/mnt/user/appdata/tordownloader/` is used if present.
- **MIT license.**

## Upgrade notes

Nothing to change. If you set the container up by hand on Unraid, you can keep it, or switch to
the template to get the field descriptions and the icon.
